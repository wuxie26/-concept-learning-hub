Transformer / 自注意力架构

Transformer · Self-Attention · Encoder–Decoder

一种完全靠自注意力（self-attention）建模序列的神经网络架构。它抛弃了循环与卷积，是 GPT / BERT / 几乎所有现代大模型的"骨架"。

预计 12 分钟 进阶难度 深度学习 · NLP

一句话三连

是什么 What

一种"每个 token 同时看其它所有 token"的神经网络，靠注意力权重决定看多少、长程依赖一次到位。

为什么重要 Why

它是 2017 年以来几乎所有 SOTA 模型的底座：BERT、GPT、T5、ViT、Sora……全都长在 Transformer 之上。

怎么实现 How

输入 → 嵌入 + 位置编码 → N 层 Encoder/Decoder（每层 = 自注意力 + 前馈网络 + 残差 + LayerNorm） → 输出。

核心机制：自注意力 + 多头 + 位置编码

Transformer 的灵魂只有三件事，看完它们就懂 80%。

1. 自注意力（Self-Attention）：每个 token 同时看其它所有 token

对序列中的每个位置，用三个可学习的矩阵 W_Q / W_K / W_V 把它的向量投影成查询 Q、键 K、值 V。然后用 Q · Kᵀ / √dₖ 得到"其它每个位置对当前位置的重要程度"，softmax 后加权求和 V。

核心直觉："我在意谁"由 Q·K 决定，"我从谁那里拿多少信息"由 softmax 后的权重决定。整段序列一步到位，没有 RNN 的"逐步传话"。

2. 多头注意力（Multi-Head）：并行学多套"关注模式"

单头注意力只能学一种"该看谁"的模式。多头把它切成 h 个子空间（如 8 个），每个头独立算一次注意力，最后拼接。每个头可能学到"看动词"、"看代词指代"、"看距离相近词"等不同模式。

3. 位置编码（Positional Encoding）：让模型"知道顺序"

自注意力是置换不变的 —— 把句子打乱它照样算得动，但没有"第几个字"的概念。位置编码把"位置信息"加到输入 embedding 上，让模型能区分"我打你"和"你打我"。原论文用固定 sin/cos；现在更常用可学习或 RoPE / ALiBi。

4. Encoder / Decoder + 残差 + LayerNorm + FFN

单层 Transformer Block = LayerNorm(x + Attention(LayerNorm(x))) + LayerNorm(x + FFN(LayerNorm(x)))。残差让梯度能穿过几十层；LayerNorm稳定训练；FFN（通常是两层 MLP）给每个位置做非线性变换。

三个递进示例

L1 · 最小

一句话里的代词指代

句子："小明把苹果给了老师，因为他饿了。" 问："他"是谁？

自注意力能让"他"在编码时重点看"小明" / "苹果"等词，从而推断出"他"最可能指"小明"。一个 RNN 要逐词扫过去才能做到；Transformer 一步到位。

注意力权重（示意）：
  "他" → "小明"  : 0.62   ← 最高
  "他" → "苹果"  : 0.18
  "他" → "老师"  : 0.12
  "他" → "因为"  : 0.08
L2 · 中等

机器翻译（Encoder-Decoder）

输入 "I love you"（3 个 token），输出 "我爱你"（3 个中文 token）。

Encoder（理解输入）：
  I    → 自注意力看 {I, love, you}
  love → 自注意力看 {I, love, you}
  you  → 自注意力看 {I, love, you}
  →  3 个上下文向量，每个都"知道整句"

Decoder（生成输出）：
  <BOS> → Cross-Attention 读 Encoder → 预测 "我"
  "我"  → 掩码自注意力只能看 {<BOS>, 我}
        → Cross-Attention 读 Encoder
        → 预测 "爱"
  "我爱" → ... → 预测 "你"
  "我爱你" → ... → 预测 <EOS>

Decoder 用掩码自注意力保证看不到未来；用 Cross-Attention 把 Encoder 的信息"读进来"。

L3 · 复杂

GPT 风格 Decoder-only：大规模预训练 + 推理

GPT 只保留 Decoder（去掉 Encoder 和 Cross-Attention），堆 96+ 层，参数上千亿。训练：让模型预测"下一个 token"。推理：给一段 prompt，自回归生成。

和原 Transformer 的关键差异：

  • 只有 Decoder，没有 Encoder。
  • 掩码自注意力让模型只能看"过去的 token"。
  • 位置编码通常用 RoPE（旋转位置编码），更利于长度外推。
  • FFN 层常用 GLU/SwiGLU 变体，参数效率更高。

这是为什么"GPT"能写文章、写代码、写诗 —— Transformer 的灵活骨架让它能装下几乎任何"序列到序列"的分布。

常见误区 / 反直觉点

✕
"Transformer = 自注意力"

不完整。一个 Block 是"自注意力 + FFN + 残差 + LayerNorm"的组合，FFN 占了大部分参数（典型 4× 维度）。

✕
"注意力权重高 = 这个词最重要"

不一定。注意力值还会被 softmax 前的 logits 大小、维度 √dₖ 等影响。解读注意力图要慎重，更可靠的归因方法是用梯度或扰动。

✕
"自注意力是 O(n²) 所以对长文本很差"

训练时确实是 O(n²)；但推理时有 KV Cache 优化，且 FlashAttention、PagedAttention、Linear Attention 等改进让它能跑到百万 token。架构本身没死。

✕
"Transformer 取代了 RNN，所以 RNN 没用了"

在大多数 NLP 场景是的，但在流式 / 极低延迟 / 设备端场景，RNN / State Space Model（Mamba 等）仍有结构性的成本优势。

自检题

点击"显示答案"看解释。

1. 在 Self-Attention 里，Q、K、V 三个矩阵来自哪里？

  1. 三个不同的输入
  2. 同一个输入 X 分别乘以三个可学习的投影矩阵 W_Q / W_K / W_V
  3. 随机初始化的固定向量
  4. 上一层 Encoder 的输出加噪声
答案：B。Q、K、V 都是同一输入 X 的"三种看法"。这就是为什么叫 Self-Attention —— 自己看自己。

2. 为什么要除以 √dₖ？

  1. 让结果更小，省内存
  2. 防止 Q·Kᵀ 的数值过大导致 softmax 梯度消失
  3. 只是一种传统，没有实际意义
  4. 让训练速度翻倍
答案：B。dₖ 大时点积的方差也大，会让 softmax 推向极端分布、梯度消失。除以 √dₖ 是为了让 logits 保持合理尺度。

3. 为什么 Decoder 要用掩码自注意力（masked self-attention）？

  1. 为了节省显存
  2. 防止模型在训练时偷看未来 token，保持自回归性质
  3. 因为 Decoder 不需要注意力
  4. 是为了让训练数据更小
答案：B。训练时如果让模型看到"未来"，就等于把答案提前告诉它。掩码让位置 i 只能看到 ≤i 的位置，匹配推理时的真实场景。

4. 位置编码为什么是必要的，不能省？

  1. 训练数据必须有位置
  2. 自注意力本身是置换不变的，必须靠位置编码注入顺序信息
  3. 为了美观
  4. 位置编码让模型跑得更快
答案：B。Self-Attention 对输入顺序不敏感 —— "猫吃鱼"和"鱼吃猫"算出同样的注意力分布。位置编码给每个 token 加上"它在第几位"的信息。

与相邻概念的边界

概念核心区别
Transformer vs RNN / LSTMRNN 逐步传话，长程依赖会衰减；Transformer 一步到位看全局，但 O(n²) 计算 / 内存。
Transformer vs CNNCNN 用固定窗口的局部卷积；Transformer 用全局自注意力，灵活但更贵。
Transformer vs State Space Model (Mamba)SSM 是 Transformer 的"O(n) 替代品"，对长序列有结构性优势，但生态远不如 Transformer 成熟。
Encoder-only vs Decoder-only vs Enc-DecBERT 走 Encoder（理解任务）；GPT 走 Decoder（生成任务）；T5 走 Enc-Dec（翻译类）。
